Spatial Analysis Approach

The project includes spatial analysis processes such as:

- Buffer-based proximity evaluation

- Intersection analysis using PostGIS functions

- View-based analytical layers

- Separation of base data and analysis schema


Core spatial functions used include:

- ST_Buffer

- ST_Intersects

- ST_Intersection


Technologies Used:
- PYTON
- QGIS
- POSTGRESQL
- GEOSERVER
   - Leaflet
   - HTML/CSS/JS
